# Lane brief (orchestrator to lane)

```
TO: {ticket} {CALLSIGN}
MODEL: {model}
DATE: {YYYY-MM-DD}
PHASE: {measure / plan / build / release}

{What to do, in full. Never "see the earlier brief".}

Scope: {exactly what is in, and what is out}
Acceptance: {observable results}
Post to: {ticket}, dated.
Then: {HOLD for GO / hold before merge / retire with a pickup note}
```

Rules for writing briefs:
- Address by ticket first, callsign second.
- One phase per brief. Measure and plan briefs end in HOLD.
- Write the whole brief every time.
- Include every standing rule that changed since the lane started.
